# 阶段四：系统裁剪

## 4.1 裁剪原则

### 绝对不能删的

1. **动态链接库** (`/system/lib/*.so`) — 所有动态链接命令都依赖
2. **servicemanager** — IPC 核心
3. **toolbox** — 提供基本命令 (ls, cat, rm 等)
4. **sh** — shell
5. **mount/umount** — 文件系统挂载
6. **busybox** — 基本工具集
7. **daemonsu** — root 权限
8. **adbd** — ADB 远程访问

### 安全删除的

1. Android 框架服务
2. IPTV 专用服务
3. 媒体/显示相关
4. 字体/媒体资源
5. IPTV 配置文件

### 曾经误删导致系统崩溃的 APK

这些 APK 删除后会导致系统服务崩溃，触发恢复机制：

- `MainControl.apk` — 主控服务
- `mcspbase.apk` — MCSP 基础服务
- `NaAgent.apk` — 网络代理
- `netmanager.apk` — 网络管理
- `nmAssistant.apk` — 网络助手
- `OSDService.apk` — OSD 显示服务
- `StbConfig.apk` — 机顶盒配置
- `Settings.apk` — 系统设置
- `SystemUI.apk` — 状态栏
- `Shell.apk` — ADB shell
- `SettingsProvider.apk` — 设置存储
- `MediaProvider.apk` — 媒体数据库
- `DefaultContainerService.apk` — 包管理

**教训：** 在内核 Patch 之前，删除这些会触发恢复。Patch 之后可以安全删除。

## 4.6 清理结果

### 空间变化

| 阶段 | 已用空间 | 空闲空间 |
|------|----------|----------|
| 原始系统 | ~600MB | ~390MB |
| 删除 APK 后 | ~280MB | ~710MB |
| 删除二进制后 | ~278MB | ~712MB |
| 删除资源后 | ~227MB | ~763MB |

### 最终 /system 结构

```
/system/
├── bin/        116 个 Linux 基础工具
├── lib/        351 个 .so 库 + modules/
├── xbin/       280 个（busybox 符号链接）
├── etc/        精简后的配置
├── fonts/      空
├── media/      空
└── vendor/     符号链接
```
